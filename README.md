# queens-gambit-zurich
Official website of Queen's Gambit Zürich

*A place for women to play chess.*

Live site (GitHub Pages, `main` branch, root): https://adelpopon.github.io/queens-gambit-zurich/

## About this site

Version 1 is a single-page landing site built with plain HTML, CSS and JavaScript. There is no build step and no external dependencies, and the fonts are self-hosted. GitHub Pages publishes the `main` branch as it is.

Every section is a self-contained block in `en/index.html` (English source; the German home page is generated from it) with its own anchor, so each one can later move to a dedicated page:

| Section | Anchor |
|---|---|
| Hero | `#home` |
| Upcoming at Queen's Gambit | `#upcoming` |
| Our Community | `#community` |
| Chess for the Next Generation (Kids Chess) | `#kids` |
| Chess with Social Impact | `#impact` |
| Collaborations & Projects | `#collaborations` |
| Who We Are | `#about` |
| Join Queen's Gambit | `#join` |

## Common updates

**Add a link (WhatsApp, Instagram, Kids registration, Impressum, privacy policy)**
Open `data/config.js` and replace `null` with the URL. The matching buttons appear automatically. While a link is `null`, its buttons are hidden or point to the contact section, so visitors never see unfinished content.

**Add or change an event**
Edit `data/events.js`, then run `python3 tools/build.py` so the dates are also written into the pages for search engines and visitors without JavaScript. Dates use `YYYY-MM-DD`. Events are sorted automatically, and past events disappear on their own. A meeting time appears only once it is filled in.

**Change text**
Edit `en/index.html`. Each section starts with a comment such as `<!-- 3. COMMUNITY -->`. Then update the German version (see below).

**German version (EN/DE)**
German is the default language (`/`), English is at `/en/`. The English page is the source. After changing English text in `en/index.html`:
1. add or update the German translation in `i18n/de.json` (key = English text, value = German; Swiss spelling with ss, never ß),
2. run `python3 tools/build.py` (needs Python 3 and Node.js). It rebuilds the German `index.html`, the legal pages and `sitemap.xml`, and stops with a list of any English text that has no translation yet.

Event texts are bilingual in `data/events.js` (`{ en: "…", de: "…" }`); short interface labels created by JavaScript are in `js/i18n.js`. The Impressum and Privacy Policy texts live in `tools/build.py`.

**Event registration**
See `registration/README.md`. The "Register for free" button appears only once the Apps Script web app URL is set in `data/config.js` (`registration.endpoint`) and the event has `registration: true`.

**Kids Chess workshop registration (Zollikon Kids Chess)**
`/kids/zollikon/` (German) and `/en/kids/zollikon/`: flexible booking of one, two or three sessions, capacity per session, configurable prices. Separate Apps Script and Sheet from WINZ; see `registration/kids-chess/README.md`. The form, and the link from the Kids Chess "Register" button, appear only once `kidsChess.endpoint` is set in `data/config.js`. Page text: `tools/kids_registration.html` (+ `i18n/de.json`), generated by `tools/build.py` (`KIDS_PAGES`).

**Shareable registration link (QGZ × WINZ)**
`https://queensgambitzurich.ch/winz/` opens the registration form directly in German (English: `/en/winz/`, or the EN switch). The pages are generated by `tools/build.py` (`REG_PAGES`) from the home page form, so the form and its translations stay in one place. After the event the page shows "Registration for this event is closed." QR code for print: `assets/qr/` (SVG and PDF are vector; PNG is 4018 px).

## Legal pages and SEO

- `impressum/`, `datenschutz/`, `en/impressum/` and `en/privacy/` are generated by `tools/build.py` and reuse the home page's header and footer.
- Every page links its other-language version with `hreflang`; `sitemap.xml` (also generated) lists both languages.
- Search metadata (title, description, canonical URL, Open Graph sharing image) is in the `<head>` of each page. Organisation data is in `en/index.html`; event data for search engines is generated automatically from `data/events.js`.
- Sharing image: `assets/brand/qgz-social-1200x630.jpg`.

## Design system

- Colours: Warm Ivory `#FDFBF7`, Neutral Sand `#EFECE6`, Natural Charcoal `#2B2A27`, Zurich Blue `#0070B4` (accent only)
- Type: League Spartan Bold for headings, Inter for body text and UI

## Custom domain

The site currently uses the GitHub Pages address. To use `queensgambitzurich.ch` later, add a `CNAME` file containing the domain, configure DNS at the domain registrar, then set the domain under Settings → Pages.

## Local preview

From the repository folder, run `python3 -m http.server 8000` and open http://localhost:8000.
